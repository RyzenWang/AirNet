## AirNet 0.2.7

全平台 Native AOT 正式发布。**仅提供便携包，不提供 setup/安装器。**

### 发布方式

Windows / macOS / Linux 全部改为 Native AOT，由 GitHub Actions 原生 runner 矩阵构建：

| 平台 | 资产 | 构建方式 |
| --- | --- | --- |
| Windows x64 | `AirNet-0.2.7-win-x64-aot.zip` | Native AOT |
| macOS arm64 | `AirNet-0.2.7-macos-arm64-aot.zip` | Native AOT |
| macOS x64 | `AirNet-0.2.7-macos-x64-aot.zip` | Native AOT |
| Linux x64 | `AirNet-0.2.7-linux-x64-aot.zip` / `.tar.gz` | Native AOT |
| Linux arm64 | `AirNet-0.2.7-linux-arm64-aot.zip` / `.tar.gz` | Native AOT |

AOT 包不是单文件：Windows 需保留同目录的 Skia / ANGLE / HarfBuzz DLL；
macOS 是 `AirNet.app`；Linux 解压后执行 `bash run.sh`。PDB / `.dbg` 已在打包时剥离。

### 修复

- 启动样例不再伪造带宽（此前固定 384.2 / 92.6 Mbps）。未测速时，仪表盘、测速页、
  报告和历史统一显示“未测速”，只有真正测速后才出现带宽数字。

### 验证

- Windows Release 构建：0 warning / 0 error。
- 单元测试：**137 passed**。
- Windows AOT：GUI、`--probe --json`、`--selftest`、`--export` 均验证通过；
  本机约 411 ms 启动 / 118.9 MB 内存。
- 五平台 AOT CI 构建矩阵：全部成功；Linux/macOS 的 GUI/CLI 运行仍待真机验收。
- 当前 AOT 压缩包参考大小：Windows 约 16.8 MB，Linux 约 15–17 MB，
  macOS 约 27–29 MB。

### 使用

**Windows**：解压后双击 `AirNet.exe`，保留同目录原生 DLL。

**macOS**：解压得到 `AirNet.app`，拖到应用程序目录；未签名/未公证，首次打开需右键 → 打开。

**Linux**：

```bash
tar -xzf AirNet-0.2.7-linux-x64-aot.tar.gz   # 或 unzip ...
cd AirNet
bash run.sh
```

需要 X11 或 Wayland（XWayland）及常见桌面库。
