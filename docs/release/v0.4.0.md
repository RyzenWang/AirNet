## AirNet 0.4.0

第一个带完整中英文切换的版本。**便携包 0.4.0，商店包 1.1.0.0**——商店包需在 Partner Center
单独提交；本页先记录 GitHub 便携版。

### 新增

- **中文 / English 运行时切换**：设置 → 外观，选择写入 `settings.json`。
  Shell、总览、实时检测、测速、站点、链路、历史、设置、分享卡片、扫描阶段和主要动态状态
  均已英文化。
- **DNS 安全预演与审计**：应用/还原前可预演命令；实际操作写本地
  `dns-operations.jsonl`，并收进诊断包。
- **历史 A/B 对比**：任选两条记录比较评分、延迟、抖动、丢包、上下行。
- 英文 README。

### 变更

- 移除独立的 `AirNet.Cli` 项目及其 Agent 文档；应用自带
  `--probe --json` / `--sites` / `--report` 参数保留。
- 中英文切换不重建窗口，使用运行时资源字典。
- 文档同步：186 项测试、Windows AOT 约 16.5MB / 0.3–0.5 s / 110–115MB。

### 验证

- 186 项单元测试。
- Windows AOT 本地验证：约 110–115MB 工作集，0.3–0.5 s 启动。
- 五平台 AOT 资产由 CI 从 `v0.4.0` tag 构建。

### 已知

- 少量低频 Core 文案（个别 NAT/错误详情、部分自定义站点校验）仍可能中文。
- macOS 未签名/未公证；macOS 与 Linux arm64 仍未真机验证。
