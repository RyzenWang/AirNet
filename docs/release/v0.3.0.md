## AirNet 0.3.0

首个能同时从 GitHub 与 Microsoft Store 安装的版本。**便携包不含 setup/安装器**；Windows / macOS / Linux 均为 Native AOT。

> 本版对应 **Microsoft Store 1.0.0.0**。两者同源，版本各自一条线——规则见 [双渠道发布](../CHANNELS.md)。

### 新增

- **Microsoft Store 打包**：`.msixupload` 未签名提交包，商店负责重新签名；`full-trust` 进程模型，保留 ICMP、原始计时与 WLAN API 能力。
- **崩溃日志**：启动最早期挂载全局钩子，写入版本、系统、运行时与异常栈；写失败也绝不影响主流程，超过 256 KB 自动滚动。
- **诊断包**：设置页那个原本点了没反应的按钮，现在会打包摘要 + 设置 + 历史 + 站点历史 + DNS 还原记录 + 崩溃日志。
- **报告带趋势**：导出的 HTML 除了本次结果，还附最近 7 天的平均分、延迟、抖动、丢包，以及最差时段的一句话结论。
- **macOS / Linux 无线数据**：此前只显示"无线"两个字；现在分别读 `system_profiler` 与 `iw` + `/proc/net/wireless`。
- **跨平台一键 DNS**：macOS 走 `osascript` 提权，Linux 走 `pkexec`，不再只有 Windows 可用。

### 变化

- **macOS 与 Linux arm64 标为实验性**：CI 能构建、包能装，但没人真机跑过。应用只在那些平台的「关于」卡片显示提示，而不是到处警告。
- **商店版没有提权**，一键 DNS 降级为"复制命令"；便携版保留一键执行。

### 修复

- 包内图标曾是彩色噪点：`System.Drawing.Icon.ToBitmap()` 解不了 PNG 压缩的 ICO 帧。
- 开始菜单磁贴偏小：母版自带 4% 边距又叠了 0.82 缩放，实际只占 75%；现在 92%，并补齐四档 DPI 变体。
- sideload 报 `0x800B0109`：`Import-Certificate` 往机器级 Root 导入会静默跳过交互确认，改用 `certutil` 并在安装前自检。

### 验证

- Windows 11 x64 真机：安装、三处图标、检测、商店版 DNS 文案、重启后历史保留，五项全过。
- 182 项单元测试。
- Linux x64 实机运行通过；macOS 与 Linux arm64 待真机验证。
