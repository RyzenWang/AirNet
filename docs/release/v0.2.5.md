## AirNet 0.2.5

从 v0.2.4 继续收口：把 DNS 实测、脚本化 JSON 和历史差值带进正式发布。
**仅提供便携包，不提供 setup/安装器。**

### 新增

- **DNS 三方实测对比**：同一个域名在本次运行中分别询问当前 DNS、223.5.5.5 和
  1.1.1.1，设置页引用三组实测耗时；只有替代方案同时快 20% 且 ≥5ms 才建议更换，
  避免“公共 DNS 一定更快”的猜测。两个公共解析器都无响应时，回退到单样本启发式。
- **`--probe --json <path>`**：一次扫描输出一份带 `schemaVersion: 1` 的 JSON，
  包含评分、延迟、四段计时、双栈、接口、代理/隧道、DNS 和诊断结论。退出码直接
  表达结论：`0` 健康（75+）、`1` 一般（60–74）、`2` 较差、`3` 扫描失败，脚本
  无需解析文本即可做门禁。
- **历史每条记录的差值**：首页“最近检测”现在显示与上一次的分数、延迟、抖动和
  下行变化，并用颜色和文字标出改善/退化；换路由器或换 DNS 后是否真的有效，
  第一屏就能回答。

### 使用

**Windows**：解压后双击 `AirNet.exe`。

**macOS**：解压得到 `AirNet.app`，拖到应用程序目录；未签名/未公证，首次打开需右键 → 打开。

**Linux**：

```bash
tar -xzf AirNet-0.2.5-linux-x64.tar.gz   # 或 unzip ...
cd AirNet
bash run.sh
```

也可以 `chmod +x AirNet && ./AirNet`。需要 X11 或 Wayland（XWayland）及常见桌面库。
