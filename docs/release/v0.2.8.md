## AirNet 0.2.8

历史趋势与分享卡片。**仅提供免安装便携包，不提供 setup/安装器**；Windows / macOS / Linux 全部为 Native AOT。

### 新增

- **历史趋势页**：7 天 / 30 天的延迟与评分曲线、按本地时段的分布、最近记录列表。晚间时段会自己给结论——"晚间平均 36.3 ms，高于整体 25.6 ms"，不用盯着图猜。
- **分享卡片**：从当前快照生成 1080 × 1350 的 PNG，带预览窗口与保存对话框；托盘菜单同一入口。
- **手动检测内置带宽测速**：延迟探针之后跑一次下行 + 上行；60 秒自动刷新只跑延迟，不消耗上行带宽。

### 修复

- **启动不再预填假数据**：以前一打开就显示样例分数、延迟、路径和带宽。现在明确「等待检测」，开始检测才写入本次结果，取消则恢复上一次真实结果。
- **趋势页终于有截图可看**：导出流水线跑在空数据目录上，之前的截图全是"还没有历史记录"。现在 `--export` 会往隔离目录里写一周确定性样例，图表、时段分布和最近记录都能展示，且完全不碰用户自己的历史。

### 平台与体积

- Windows x64 AOT：16.8 MB zip；本机启动 0.5 s、内存约 131 MB；需保留同目录原生 DLL（Skia / HarfBuzz / GLES）。
- Linux x64 / arm64 AOT：约 16 MB，要求 glibc ≥ 2.35。
- macOS arm64 / x64 AOT：约 27–29 MB，未签名未公证。
- Linux arm64 与 macOS 双架构为 CI 构建通过、运行待真机验证。

### 测试

- 148 项单元测试（0.2.7 时为 142）；本轮新增样例历史一周、确定性与写盘格式的覆盖。
