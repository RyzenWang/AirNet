## AirNet 0.2.4

上下行测速、IPv4/IPv6 双栈、代理/VPN 识别。**仅提供便携包，不提供 setup/安装器**。

### 新增

- **上行测速**：测速页现在两个方向都测。下行按 4 秒时间预算读取（不是字节数），上行以单缓冲流式发送 4MB。任一向失败只显示该项「未测出」，不拖累另一向，也不写假数字。
- **IPv4/IPv6 双栈对照**：同一主机名用两种协议族各 5 次 TCP 握手，与首包分解并行执行，给出「均衡 / IPv6 更快 / IPv6 偏慢」。IPv6 偏慢时进诊断——多数应用优先尝试 IPv6，回退前那次超时会直接算进首包。阈值 0.9 / 1.3 有单测；没有 IPv6 时标「仅 IPv4」，不影响评分。
- **代理 / VPN 识别**：测量经过系统代理或隧道时明确标注。两者影响范围不同，所以措辞也分开：代理只影响 HTTP(S) 探测（带宽、出口、网站延迟），隧道影响全部（含原始 TCP 计时）。代理是 Info，VPN 是 Warn。
- **上下行不对称结论**：下行快而上行低于 10 Mbps 时，直接说出先受影响的是什么——视频会议、云端备份、大文件回传。
- 新增 `--speedtest <path>` 无界面双向测速，`--selftest` 增加 `interference=` 行。

### 修复

- **图标底色**：v0.2.3 换成暖橙后，`.ico` 仍是旧的青绿 `#2E6F63`，资源管理器里是绿块配橙窗口。现在 `.ico` 与 macOS 的 `.icns` 都由 `docs/icon-concepts/make-icon.py` 按品牌色生成，改色只需一个参数。
- **网站延迟绕过系统代理**：探针用裸 socket，代理机器上测的是浏览器不会走的路径。现在按系统代理建立 HTTP CONNECT 隧道，代理跳计入 TCP 段，并在页面标「经代理」、在 `--sites` 输出 `viaProxy=`。
- **慢链路下行报 0**：旧探针要求 12MB 在 8 秒内读完，低于约 12 Mbps 一律超时。改为时间预算制；传输中断时按已收到的字节计算速度，而不是抛异常或归零。

### 验证

- Wi-Fi 采样在真实无线网卡上验证通过（SSID / 信号质量 / 协商速率 / PHY 代际）。
- 101 项单元测试（0.2.3 时为 70）。
