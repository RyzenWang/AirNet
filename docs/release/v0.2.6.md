## AirNet 0.2.6

M3 场景补全：Wi-Fi 邻区、游戏模式和会议模式。**仅提供便携包，不提供 setup/安装器。**

### 新增

- **Wi-Fi 邻区扫描（Windows）**：通过 WLAN BSS 列表只读列出 SSID / BSSID / 信号质量 /
  PHY / 协商速率；同 SSID 多热点时提示优先靠近强 AP。纯有线电脑会明确提示“无需邻区扫描”，
  不显示空失败。Windows 的 BSS 结构不暴露信道，页面不会编造信道建议。
- **游戏模式**：向公共 STUN 端点发送 6 次 UDP binding，给出 UDP 可达性、RTT、抖动、丢包
  和 NAT 映射行为启发式（端口保持 / 端口变化）。这不是完整 NAT 类型，也不是实际游戏服务器
  RTT；STUN 被拦截时会明确显示 UDP 不可达。
- **会议模式**：2MB 上行 + 8 次 TCP 握手，给出上行、延迟、抖动、丢包，以及
  1080p / 720p / 风险三档结论；缺少上行时不会用 0 冒充。

### 验证

- Windows Release 构建：0 warning / 0 error。
- 单元测试：**135 passed**（v0.2.5 为 123）。
- 实测：STUN `UDP 可达`；会议模式 4.5 Mbps 上行 → “可开 720p / 语音”；
  有线开发机邻区扫描正确降级。
- Linux x64：真实环境启动验证；Linux arm64 / macOS 未真机运行。
- 游戏/会议模式是独立动作，不进入 3 秒主扫描或自动刷新。

### 使用

**Windows**：解压后双击 `AirNet.exe`。

**macOS**：解压得到 `AirNet.app`，拖到应用程序目录；未签名/未公证，首次打开需右键 → 打开。

**Linux**：

```bash
tar -xzf AirNet-0.2.6-linux-x64.tar.gz   # 或 unzip ...
cd AirNet
bash run.sh
```

也可以 `chmod +x AirNet && ./AirNet`。需要 X11 或 Wayland（XWayland）及常见桌面库。
