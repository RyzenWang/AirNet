# Microsoft Store listing 材料

Partner Center 里要填的东西都在这里，逐项可复制。

## 基本信息

| 字段 | 值 | 备注 |
| --- | --- | --- |
| 应用名称 | `AirNet` | 备选：`AirNet 网络诊断`、`AirNet Diagnostics` |
| 类别 | 实用工具 › 系统工具 | Utilities & tools |
| 年龄分级 | 3+ | 无用户生成内容、无广告、无社交功能 |
| 支持的语言 | 中文（简体）、English | 界面目前为中文，英文仅隐私政策 |
| 价格 | 免费 | |
| 系统要求 | Windows 10 版本 2004（19041）或更高，x64 | 与清单 `MinVersion` 一致 |

## 短描述（≤ 270 字符）

> 点一下，三秒告诉你网络好不好：延迟、抖动、丢包、上下行带宽、网站延迟、逐跳路径，并直接指出问题在路由器、运营商还是对端。

## 长描述

> **三秒，一句话说清问题在哪。**
>
> AirNet 不是又一个测速网站套壳。它按层测量——ICMP 丢包、TCP 握手计时、DNS/TCP/TLS/首包四段分解——然后把结果翻译成人能看懂的一句话：是家宽入户这一段慢了，还是运营商出口拥堵，还是对方服务器不响应。
>
> **主要功能**
>
> - 一键体检：评分、健康结论、场景预估（网页、4K、游戏、会议、大文件）
> - 亚毫秒抖动：基于 TCP 握手计时，而不是 1ms 分辨率的 ICMP
> - 网站延迟：11 个常用站点 + 最多 8 个自定义站点，只读首字节，不下载页面
> - 链路路径：逐跳耗时与突变点，直接看出哪一跳开始变差
> - 带宽测速：下行 4 秒预算 + 4MB 上行，任一方向失败只显示「未测出」
> - IPv4/IPv6 双栈对照：告诉你 IPv6 是否真的更快
> - Wi-Fi 体检：信号、协商速率、PHY 代际；Windows 下可只读扫描邻区
> - 历史趋势：7/30 天曲线与时段规律，自动指出「晚间比整体慢多少」
> - 诊断报告：单文件 HTML，可打印成 PDF 分享给运营商客服
> - 代理 / VPN 识别：明确标注「经代理」并说明哪些数字因此失真
>
> **克制的地方**
>
> - 无驱动、无常驻进程、不开机自启，关闭窗口即退出
> - 不收集数据、无账号、无分析 SDK；历史只存在本机，30 天后自动裁剪
> - 未测速就显示「未测速」，不写 0，也不编样例数字
>
> **说明**：Microsoft Store 版无法自动提权，因此「一键修改 DNS」只显示命令供复制；
> 便携版保留一键执行。

## 系统要求与兼容性

- 架构：x64
- 最低系统：Windows 10 2004（build 19041）
- 需要：以太网或 Wi-Fi 连接；建议保留系统自带的 Teredo/ICMP 设置以便测量丢包

六张，1600 × 900，浅色主题，放在 `docs/store/screenshots/`：

| 文件 | 页面 | 讲什么 |
| --- | --- | --- |
| `01-overview.png` | 总览 | 一句话结论 + 最近检测的评分变化 |
| `02-monitor.png` | 实时检测 | 指标、诊断结论、首包四段分解 |
| `03-speed.png` | 带宽测速 | 上下行双环 + 近 6 次趋势 |
| `04-sites.png` | 网站延迟 | 11 站分段条 + 国内/国际对比结论 |
| `05-history.png` | 历史趋势 | 7 天曲线 + 时段观察 |
| `06-path.png` | 链路路径 | 三段归因 + 逐跳 |

重新生成：

```powershell
AirNet.exe --export docs/store/screenshots --scale 1 --size 1600x900
```

> 必须用 `--size` 放大窗口，不要用 `--scale 2`：Avalonia 在 2× 缩放下会复用 1× 字形缓存，中文发糊。
> 导出会用隔离目录里的样例数据填充，不会带上本机真实历史。

## 政策与支持 URL

| 字段 | 值 |
| --- | --- |
| 隐私政策 | `https://github.com/RyzenWang/AirNet/blob/main/docs/PRIVACY.md` |
| 支持 | `https://github.com/RyzenWang/AirNet/issues` |
| 网站 | 可选；如启用 GitHub Pages，指向 `docs/` |

> Store 要求隐私政策是一个**可公开访问的 URL**。GitHub 的 blob 页可用，但更稳妥的是
> 开启 GitHub Pages 后指向渲染版；内容与 `docs/PRIVACY.md` 同源。

## 提交前检查

1. `packaging/msix/Build-Msix.ps1 -Version x.y.z.0 -ForStore -IdentityName <name> -Publisher "CN=<id>"`；
2. 产物是**未签名**的 `.msix`——商店会重新签名，自己签了反而会被拒；
3. 版本号四段、末位为 0，且高于上一次提交；
4. 隐私政策 URL 可打开、内容与 `docs/PRIVACY.md` 一致；
5. 截图不含真实公网 IP、真实 SSID 或个人信息（导出已用样例数据规避）。
