AirNet

动效方案对比

三版可点、可循环的动效稿。每一版都是「检测中 → 检测完成」的完整过程，用的就是应用里的色板、字号与卡片布局。 点「重播」逐版对比，选一版我再落到 Avalonia 里。

A · 仪表扫描

强度中

扫描期间一条高光带自上而下扫过页面，环变成旋进的弧。完成后高光淡出，环与数字归位。 像仪器在进行测量，不打断阅读。

扫描带 1.6s 循环 环旋进 1.15s/圈 归位 550ms
实现成本 低（1 个 overlay 层 + 环的 indeterminate 模式）

B · 数字涌入

强度中高

扫描期间数值真实地在跳、曲线边画边推进，指标准实时刷新。完成瞬间每块指标闪一下锁定，环轻微过冲后回稳。 把"在测"变成"在读数"。

数值 180ms/跳 曲线连续描画 锁定闪 450ms · 过冲 1.035
实现成本 中（探针要按样本流式上报）

C · 剧场

强度高

开始时整页模糊退后，中央出现呼吸的检测球。完成瞬间球收起，内容从下方浮入、环画出、指标依次进场。 有过场感，也最容易显得慢。

模糊 1.6px · 0.45 不透明 波纹 1.8s 循环 入场 500ms 错峰 60ms
实现成本 高（全屏 overlay + 模糊特效）

怎么选：A 最安全，任何机器上都稳，连续测十次也不烦；B 的信息密度最高，但要求把探针改成逐样本回传（现在是一轮结束后一次性出结果）， 是这里面唯一需要动内核的一版；C 第一眼最抓人，代价是每次检测都要占用整个界面 2 秒，高频使用时容易变成负担。

三版都不改布局，只改透明度、描边进度与位移——这也是 Features.Motion 能一键关掉的原因（截图与 CI 用）。
